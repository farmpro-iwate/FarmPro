# FarmPro 全国子牛市場結果通知 — データ連携仕様（確認用）

## 現状（2026-11-24）
PR #928では、47都道府県の選択、自由入力の市場登録、通知希望設定を専用 localStorage キー `farmpro-market-watchlist-v1` に保存する。実際の市場結果の取得・通知は未実装。データ保存・同期機能は変更しない。

## 確認した公開情報
1. 全国肉用牛振興基金協会「家畜市場データベース」https://www.nbafa.or.jp/mkt.html
   - 全国→地域→都道府県→市場の階層検索、家畜取引頭数、過去の開催日等。
   - CSVエクスポート画面 https://www.nbafa.or.jp/mkt/export.php には年・都道府県・市場名・品種/性別・子牛などの絞込みがある。
   - ただし公開データは調査結果をもとにした一部データ。市場開催当日の速報・去勢/雌別平均価格を全市場で取得できるとは未確認。
2. 農畜産業振興機構「肉用子牛取引情報」https://www.alic.go.jp/operation/livestock/calf-report.html
   - 月別集計、Excel/PDF等を公開。消費税込み価格。
   - 2026-11-20のお知らせで、2026-12から月次更新を毎月15日1回に変更と告知。
   - 月次情報は個別市場の開催終了直後の通知とは別用途。

## データ契約（新規モジュールのみ）
- MarketCatalog: marketId（提供元の安定ID。なければ内部採番）、prefecture、name、aliases、sourceId、active、verifiedAt。
- MarketResult: marketId、heldOn、publishedAt、fetchedAt、breed、sex、headCount、averageYen、priceTaxBasis、sourceUrl、sourceRevision、status（速報／確定）。
- EventKey: `sourceId:marketId:heldOn:breed:sex:sourceRevision`。再取得でも重複通知しない。
- 欠損値は「未公表」。市場単位か全国月次かを明示し混同しない。価格の税込/税抜も明記する。
- 公表元の情報を訂正した場合は更新として扱う。前回差の計算は同一市場・品種・性別・税込条件のみ。

## 段階的な実装
1. 市場マスタ: 公表元の正式な市場ID・市場名と別名の対応表を準備する。現在の自由入力の市場名を自動結合せず、利用者確認後に市場IDへ紐付ける。
2. データ取得: 公表元のAPIまたは許諾済みデータ配信を使用。CSV/Excelの仕様は実物の項目・文字コード・利用条件を確認してからアダプタを作る。取得が失敗した場合に古い価格を最新として表示しない。
3. 結果画面: 市場・開催日・去勢/雌・頭数・平均価格・公表日・出典・更新状況を表示。月次全国情報は別枠。
4. 通知: 定期確認はサーバー側ジョブ。公表日と出典が確定した場合にのみ差分を通知する。利用者の選択市場を参照し、通知の有効/無効・通知済みイベントを分離管理する。
5. バックアップ・同期: 既存の IndexedDB / SQLite / バックアップ形式 / 販売保存処理に一切変更しない。利用者設定を複数端末で同期する必要が生じた場合は別途設計・同意を取る。

## 安全ゲート
- 外部ページの自動取得・再配布の許諾と技術条件を確認するまでは、自動収集を開始しない。
- 正式な市場名を揃えるまで架空の選択肢を実在市場として表示しない。
- 現在の「通知を希望」は通知予約ではなく、端末内の希望設定である。
- PRはDraftのまま、検証と利用者確認前にmainへマージ・Render公開しない。
