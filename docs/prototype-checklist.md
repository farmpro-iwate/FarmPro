# FarmPro 試用開始チェックリスト

FarmProを知り合いへ渡して試用を始める前に、現在の公開版と実際の操作を確認するためのチェックリストです。

## 目的

- 試用者が迷わず使い始められるか確認する
- 登録したデータが端末内へ保存されることを確認する
- バックアップと復元の場所を確認する
- スマホで日常作業が無理なく行えるか確認する
- 不具合や要望を報告できることを確認する

- [ ] GitHub Pages公開版を開ける

## 試用開始の判断

次の項目が確認できたら、知り合いへの試用を開始できます。

- 公開版をスマホで開ける

- 繁殖牛・繁殖・分娩・子牛の基本操作ができる
- バックアップを保存できる
- 不具合・要望を報告できる
