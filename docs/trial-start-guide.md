# FarmPro 試用開始のご案内

FarmProを試していただき、ありがとうございます。

FarmProは、繁殖和牛農家の日々の記録をスマートフォンで管理するための試用版です。

現在は、1台のスマートフォンで使うことを前提にしています。

## 1. FarmProを開く

次のURLをSafariまたはChromeで開いてください。

https://farmpro-iwate.github.io/FarmPro/

白画面にならず、FarmProのホーム画面が表示されれば正常です。

## 2. ホーム画面へ追加する

毎回URLを入力しなくても使えるように、スマートフォンのホーム画面へ追加できます。

### iPhone

1. SafariでFarmProを開く
2. 画面下の共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 「追加」を押す

### Android

1. ChromeでFarmProを開く
2. 画面右上のメニューを開く
3. 「ホーム画面に追加」または「アプリをインストール」を選ぶ

## 3. 最初に登録する内容

最初から全部を登録する必要はありません。

まずは、次の内容だけ登録してください。

1. 農場名
2. よく使う種雄牛
3. 繁殖牛を1頭
4. 必要に応じて予定を1件

操作に慣れてから、少しずつ登録を増やしてください。

## 4. 最初に試していただきたい操作

次の操作を試してください。

- 繁殖牛を登録する
- 繁殖記録を登録する
- 人工授精または受精卵移植を登録する
- 分娩記録を登録する
- 子牛台帳を確認する
- 予定を登録する
- 個体カルテを確認する

全部を一度に試す必要はありません。

普段の作業で必要なところから使ってください。

## 5. データの保存について

FarmProへ登録したデータは、使用している端末の中へ保存されます。

次の点に注意してください。

- 別のスマートフォンへ自動では移りません
- 別のブラウザには自動では移りません
- ブラウザの履歴やサイトデータを削除すると、データが消える場合があります
- プライベートブラウズでは使用しないでください

いつも同じ端末、同じブラウザで使用してください。

## 6. バックアップについて

大切なデータを守るため、定期的にバックアップを保存してください。

1. FarmProの設定を開く
2. 「バックアップ／復元」を開く
3. 「バックアップを保存」を押す
4. 保存されたJSONファイルを確認する

特に、次の前には必ずバックアップを保存してください。

- スマートフォンを交換する前
- ブラウザのデータを削除する前
- 大きな登録作業を行った後

バックアップファイルは、メール、クラウド、PCなど別の場所にも保管してください。

## 7. 耳標未装着の子牛について

耳標がまだ付いていない子牛も登録できます。

その場合は、次のように表示されます。

- 耳標番号：未装着
- 仮管理番号：TEMP-...
- 名号：未登録

耳標を付けた後に、正式な耳標番号へ変更してください。

## 8. 不具合や要望について

使っていて分かりにくい場所や、直してほしい場所がありましたら、FarmPro内の「不具合・ご要望を送る」から報告してください。

報告するときは、次の内容があると確認しやすくなります。

- 使用したスマートフォン
- 使用したブラウザ
- 操作した画面
- 起きた内容
- エラーメッセージ
- スクリーンショット

FarmProへ登録した牛のデータが、自動で送信されることはありません。

## 9. 試用中に教えていただきたいこと

特に、次の点を教えてください。

- 分かりやすかったところ
- 迷ったところ
- ボタンが押しにくかったところ
- 表示が見にくかったところ
- 普段の作業に合わなかったところ
- 追加してほしい機能

正しい使い方よりも、実際に使って感じたことをそのまま教えてください。

## 10. 試用時のお願い

FarmProは現在、試用版です。

大切な記録は、紙や今まで使用している方法も残しながら試してください。

FarmProだけに記録を任せる運用は、試用期間が終わるまで行わないでください。
