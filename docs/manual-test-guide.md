# FarmPro 動作確認手順

## 1. この手順の目的

この資料は、FarmProの公開版をスマートフォンまたはPCで確認するための手順です。

現在のFarmProは、次の構成で運用します。

- 公開版をブラウザで利用
- PWAとしてホーム画面へ追加可能
- データは端末内のIndexedDBへ保存
- バックアップファイルを利用してデータを保管・復元
- サーバー起動やlocalhost確認は不要

## 2. 公開版を開く

次のURLを開きます。

https://farmpro-iwate.github.io/FarmPro/

確認する内容：

1. 白画面にならず、FarmProのホーム画面が表示される
2. 上部メニューや各管理画面が正常に開く
3. 文字やボタンが画面外にはみ出していない
4. スマートフォンでも操作できる

## 3. PWAとして追加する

### iPhone

1. Safariで公開版を開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 追加したFarmProアイコンから起動する

確認する内容：

- ホーム画面にFarmProのアイコンが表示される
- アイコンから起動できる
- 通常のアプリに近い画面で表示される

### Android

1. Chromeで公開版を開く
2. メニューを開く
3. 「ホーム画面に追加」または「アプリをインストール」を選ぶ
4. 追加したFarmProから起動する

## 4. 基本画面の確認

ホーム画面から、現在表示されている各メニューを開きます。

主な確認対象：

- 農場ストーリー
- 繁殖管理
- 人工授精
- 受精卵移植
- 分娩管理
- 個体カルテ
- 子牛台帳
- その他の管理
- 設定

確認する内容：

- 画面が開く
- 戻る操作ができる
- ボタンを押しても白画面にならない
- 表示される名称が現在の用語に統一されている

## 5. データ登録の確認

試験用のデータを1件登録します。

確認する内容：

1. 入力欄へ文字や日付を入力できる
2. 保存ボタンを押せる
3. 保存成功の表示が出る
4. 一覧画面へ登録内容が表示される
5. 画面を閉じて開き直してもデータが残る

個体の表示は、耳標番号を中心に確認します。

耳標未装着の子牛は、次のように表示されることを確認します。

- 耳標番号：未装着
- 仮管理番号：TEMP-...
- 名号：未登録

## 6. IndexedDB保存の確認

FarmProのデータは、使用中の端末内に保存されます。

確認手順：

1. 試験用データを登録する
2. ブラウザを閉じる
3. 同じ端末・同じブラウザでFarmProを開く
4. 登録したデータが残っているか確認する

注意：

- 別の端末には自動で同期されません
- ブラウザの履歴やサイトデータを削除すると、保存データが消える場合があります
- プライベートブラウズでは使用しません

## 7. バックアップ保存の確認

1. 設定画面を開く
2. 「バックアップを保存」を押す
3. JSONファイルが保存されることを確認する

確認する内容：

- バックアップファイルが作成される
- ファイル名に日時が含まれる
- 農場名と農場IDがバックアップに含まれる
- エラーが表示されない

バックアップファイルは、端末故障やデータ消失に備えて別の場所にも保管します。

## 8. バックアップ復元の確認

復元確認は、必要な場合だけ慎重に行います。

1. 設定画面を開く
2. 「バックアップから復元」を押す
3. 保存済みのJSONファイルを選ぶ
4. 復元前の確認画面を見る
5. 農場名と農場IDを確認する
6. 復元を実行する
7. 画面再読み込み後にデータを確認する

注意：

- 復元すると、現在の端末内データが置き換わります
- 復元前に、現在データのバックアップを保存します
- 別の農場のバックアップを誤って復元しないようにします

## 9. 分娩と子牛登録の確認

分娩登録では、次を確認します。

- 実分娩日に未来日を入力できない
- 耳標未装着でも子牛台帳へ登録できる
- 仮管理番号が自動で発行される
- 分娩登録の成功またはエラーが表示される
- 登録後、子牛台帳に正しく表示される

## 10. 予定一覧の確認

確認する内容：

- 予定日の3日前から一覧へ表示される
- 期限切れの予定も引き続き表示される
- 予定内容を選択できる
- 「その他」を選ぶと入力欄が表示される
- 検索欄と一覧の表示が「予定内容」に統一されている

## 11. 不具合・要望フォームの確認

1. 不具合・要望フォームへのリンクを開く
2. Googleフォームが表示される
3. 報告内容を入力できる
4. 送信できる

報告する際は、次の内容があると確認しやすくなります。

- 使用した端末
- 使用したブラウザ
- 操作した画面
- 起きた現象
- エラーメッセージ
- スクリーンショット

## 12. 試用時の注意

- 実データを入れる前に、試験用データで操作を確認します
- 定期的にバックアップを保存します
- 端末交換前には必ずバックアップを保存します
- 別端末へデータは自動同期されません
- 公開版の更新後も、保存済みデータが残っているか確認します

## 13. 問題が起きた場合の確認順

1. 画面を再読み込みする
2. 公開版URLを開き直す
3. 同じ端末・同じブラウザで開いているか確認する
4. プライベートブラウズではないか確認する
5. バックアップファイルがあるか確認する
6. スクリーンショットを保存する
7. 不具合・要望フォームから報告する

## 14. 次の改善を決める基準

次のStarter Packは、以下の優先順で決めます。

1. 白画面やエラー
2. 登録や保存ができない場所
3. バックアップや復元の問題
4. スマートフォンで使いにくい場所
5. 耳標番号が見にくい場所
6. 操作がややこしい場所
7. 見た目の整理
