# 分析：母牛の繁殖成績

既存の「分析」画面内の「繁殖成績」タブで表示する。保存済みのreadonlyスナップショットを使用し、牛台帳、繁殖記録、保存・同期処理やDB構造は変更しない。人工授精（AI）と受精卵移植（ET）の両方を、実施方法が分かる形で同じ一覧に表示する。

## 画面構成

上段の入口は「農場全体／繁殖成績／産子・販売成績」の3つとする。旧「母牛ごとの比較」の繁殖表と独立した繁殖成績を統合し、一覧・グラフの切り替えも1つにする。既存の `scope=mothers` と `scope=efficiency` は同じ統合画面を開き、`scope=offspring` は産子・販売成績を開く。農場全体の内部タブは「繁殖の推移」として母牛の比較と区別する。

母牛、分娩実績、分娩後の日数、受胎率、授精・移植時の農場参考値の5列に関連項目をまとめる。スマートフォンは同じ項目を母牛ごとのカードに表示する。受胎率・授精／ET実施回数はET対応の繁殖成績モデルに統一し、旧「確定妊鑑の受胎割合」は統合画面に併記しない。

年の初期値は現在年とし、全期間も選べる。母牛検索と並び順は表示行だけに適用し、農場全体の集計カード・グラフ基準値・発情発見率等の対象頭数は変えない。産子の性別・分娩母／血統上の母の選択は産子・販売成績に限定する。

一覧・カード・グラフの「詳細」は同じ母牛の履歴を開く。選択期間の分娩後の経過と、全期間の分娩履歴・過去の産子や出荷販売を区別して表示する。年・検索・上段の入口を変えた場合は詳細の選択を解除し、以前の条件の履歴を残さない。

## 実績の振り返り

| 項目 | 計算・期間 |
| --- | --- |
| 平均分娩間隔 | 対象年の分娩記録に対応する、確認済みの間隔の平均。全履歴から計算済みの間隔を使用し、前年の前回分娩との間隔や初回取込履歴の間隔を失わない。農場平均は採用した間隔を1件ずつ集計し、母牛平均の平均にはしない。 |
| 分娩回数・期間内最終分娩日 | 選択年・基準日以前の分娩実績を数え、その期間内の最終日を表示する。台帳の産次とは区別する。期間内に記録がない場合、他の年の最終日で補わない。 |
| 分娩後初回の授精・移植までの日数 | 実分娩日から次の分娩までの保存済み記録中、最初の人工授精日またはET移植日との差。方法を区別して表示する。分娩した年で絞る。40〜50日は人工授精についてのユーザー指定の管理目安で、ETへ一律に適用せず、回復の診断や自動的な良否判定には使わない。 |
| 空胎日数 | 受胎を確認できた授精日と分娩日の差。鑑定日・分娩予定日で代用しない。ETは記録された発情日を基準とし、欠損・日付矛盾なら計算しない。分娩した年で絞る。 |
| 受胎率 | 受胎が確認されたAI・ET実施件数÷AI・ET実施件数×100。授精日・移植日で年を絞り、結果は読込時点までの確定鑑定を参照。人工授精とETそれぞれの率・実施回数・受胎件数・未確定件数も表示する。未確定がある方法の率と合計率は確定せず、鑑定待ちを不受胎には数えない。実施記録がない方法は0%にしない。 |

分娩前の授精・移植を産後の実績としない。隣り合う分娩ごとに経過を分け、初回・空胎日数の平均は確認できた実績だけを重み付けせず1件ずつ集計する。母牛平均の平均にはしない。受胎未確認の最終分娩後の経過日数は別に表示し、空胎日数の平均には混ぜない。空胎日数の標本数は「計算対象○件」と表記し、「受胎○件」と混同しない。分娩日がなく日数を計算できなくても、対応するET・妊娠鑑定が確認できればETの受胎実績を表示できる。

同一母牛・同一方法・同日実施の重複や照合不明は確認事項を表示する。重複した早い授精を捨てて後の授精を「初回」とすることは避ける。同一分娩後の複数受胎は喪失・再受胎か重複かを推測せず、該当する空胎日数・受胎率は要確認とする。

## 21日間の共通対象群

母牛一覧には、対象年のその牛の直近の人工授精日またはET移植日を終点とする21日間の「農場の参考値」を直接表示する。個体1頭の発情発見率ではない。表示済みの一覧と重複する下部の集計・計算説明セクションは再追加しない。

開始日〜開始日+20日の両端を含む21日間について、開始時点で在籍し、産後40日以降で、受胎確認等による除外条件に該当しない牛を暫定候補にする。体調・休養は自動判定できないため、参考値であることを表示する。全台帳頭数や実施した牛だけを分母にしない。分娩日不足等で対象条件が不明な牛に期間内の発情・授精・移植があれば、その牛を黙って除いた小さい分母で率を出さず、理由を表示する。ET予定・ET実施だけを理由に候補から除外しない。期間内の実施で受胎した牛は、現在妊娠中でも当時の対象に含める。

- 発情発見率：同じ21日間に実際の発情を記録した対象牛の頭数÷同じ対象頭数×100。人工授精・ET・発情のみで未実施の記録を含め、1頭は1回だけ数える。移植予定・移植中止でも確認した発情の記録は保持する。実際の発情日は独立に集計し、移植日・予定日・移植日からの逆算で補わない。
- 同期間の受胎率：対象牛の期間内AI・ETの受胎確認件数÷対象牛の期間内AI・ET実施件数×100。期間後の鑑定も、現在までに確定していれば使用する。
- 妊娠率：同じ対象牛の期間内AI・ETで受胎を確認した頭数÷同じ対象頭数×100。1頭は1回だけ数える。発情だけで処置しない牛もいるため、発情発見率と受胎率を掛け算して代用しない。

同一牛の不受胎後の再実施は、件数と頭数を区別して計算する。同じ周期の複数受胎や受胎後の再実施など、経過を確認できない場合は関連する率を確定しない。開始前受胎があり後の分娩が未確認、対象期間内の照合不明・重複なども要確認とする。対象頭数が正で実施ゼロなら受胎率は分母がないため表示せず、記録に基づく妊娠率は0%になる。結果未確定があれば受胎率・妊娠率を確定しない。発情未記録の実施は発見頭数に加えず、発情日の不足と妊娠鑑定待ちを混同しない。

発情発見率は保存済みの実際の発情記録に基づく参考値で、記録されていない発情を発見済みと推定しない。妊娠率・受胎率とは独立して計算し、対象群の履歴や記録の完全性を保証する値にはしない。
