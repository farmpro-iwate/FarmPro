# 分析：繁殖成績の5指標

既存の「分析」画面内の「繁殖成績」タブで表示する。保存済みのreadonlyスナップショットを使用し、牛台帳、繁殖記録、保存・同期処理やDB構造は変更しない。対象牛の選択は画面内の一時状態とし、対象期間の変更で解除する。

## 実績の振り返り

| 項目 | 計算・期間 |
| --- | --- |
| 分娩後初回授精日数 | 実分娩日から次の分娩までの保存済み記録中、最初の人工授精日との差。分娩した年で絞る。40〜50日はユーザー指定の管理目安として表示し、回復の診断や自動的な良否判定には使わない。 |
| 空胎日数 | 受胎を確認できた授精日と分娩日の差。鑑定日・分娩予定日で代用しない。ETは記録された発情日を基準とし、欠損・日付矛盾なら計算しない。分娩した年で絞る。 |
| 受胎率 | 受胎が確認されたAI実施件数÷AI実施件数×100。授精日で年を絞り、結果は読込時点までの確定鑑定を参照。未確定があれば率は確定せず、全授精回数と未確定件数を併記。ETは混ぜない。 |

分娩前の授精を産後の実績としない。隣り合う分娩ごとに経過を分け、初回・空胎日数の平均は確認できた実績だけを重み付けせず1件ずつ集計する。母牛平均の平均にはしない。受胎未確認の最終分娩後の経過日数は別に表示し、空胎日数の平均には混ぜない。

同一母牛・同一方法・同日実施の重複や照合不明は確認事項を表示する。重複した早い授精を捨てて後の授精を「初回」とすることは避ける。同一分娩後の複数受胎は喪失・再受胎か重複かを推測せず、該当する空胎日数・受胎率は要確認とする。

## 21日間の共通対象群

画面ではまず「授精した牛」「受胎を確認」「妊娠鑑定待ち」の頭数を表示する。対象牛の選択前でも、期間内の農場全体の確認できた記録を表示できるが、全台帳頭数を率の分母として自動採用しない。期間と対象牛の設定は1つにまとめ、選択後に率を表示する。計算式や個別の除外理由は折りたたみ、未鑑定・再鑑定待ちと、流産や日付不整合など確認が必要な記録を区別する。頭数は個体ごとに数え、授精回数は別記する。

開始日〜開始日+20日の両端を含む21日間を選び、開始時点で在籍し授精対象だった未妊娠牛を利用者が選択する。全台帳頭数や授精した牛だけを自動的に分母にしない。休養・妊娠・ET対象などの適否は画面で確認してもらう。

- 発情発見率：同じ21日間に実際の発情日とAI実施日が揃う対象牛の頭数÷選択した対象頭数×100。1頭は1回だけ数える。
- 同期間の受胎率：対象牛の期間内AIの受胎確認件数÷対象牛の期間内AI回数×100。期間後の鑑定も、現在までに確定していれば使用する。
- 妊娠率：同期間・同対象の発情発見率×受胎率÷100。

同一牛に21日内の複数AIがあれば、頭数と回数を混ぜて積を出さず、受胎率・妊娠率を要確認とする。発情日欠損・期間外、期間内ET、開始前受胎があり後の分娩が未確認、対象期間内の照合不明・重複などは関連する率を確定しない。授精ゼロなら発情発見率は0%を許すが、受胎率と積には分母がないため妊娠率0%は作らない。

この方式は発情確認とAI記録に基づく指標。定時授精・発情を捉えても授精しなかった場合を含む純粋な発情観察率とは区別する。対象群の履歴が完全かは利用者の確認を要する。
