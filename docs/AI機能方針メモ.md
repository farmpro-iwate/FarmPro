# FarmPro AI機能方針メモ

## AI搭載で実現したいこと
AIは、正式データを勝手に保存するものではなく、入力・検索・要約・確認を補助する役割とする。

## AI機能の種類
1. 音声入力
   - 話した内容を文字にする。

2. 内容解析
   - 牛番号、活動区分、日付、時刻などを読み取る。

3. 登録候補作成
   - 発情、授精、治療、分娩などの登録候補を作る。

4. 検索・質問応答
   - 「123番の前回授精はいつ？」などに答える。

5. 要約
   - 今日の作業、予定、注意牛などをまとめる。

6. 異常・矛盾チェック
   - 重複記録、妊娠中の授精、休薬中の出荷などを注意表示する。

## 最初に試す機能
音声入力 → AIによる文字起こし → 内容解析 → 登録候補表示 → 人が確認 → 保存

## 開発方針
- mainは変更しない。
- 別ブランチで本物のAI音声活動登録を試す。
- 既存の試用版を壊さない。
- AIは正式データを自動保存しない。
