# FarmPro

繁殖和牛農家向けの農場管理Webアプリです。

日々の記録を、牛一頭ごとの履歴、今後の予定、注意すべき牛、農場全体の状況、経営判断へつなげることを目的としています。

## 本番版

https://app.farmpro-app.jp/

本番開発ブランチ：`agent/paid-mainline-sync`

## 現在の料金プラン

- Free：繁殖雌牛10頭まで
- Standard：繁殖雌牛11〜50頭、月額2,750円（税込）
- Pro：繁殖雌牛51頭以上、月額5,500円（税込）
- クレジットカードは月払い、銀行振込は年払い（1年分一括）
- 銀行振込の年額：Standard 33,000円（税込）、Pro 66,000円（税込）
- 支払方法：クレジットカード（Stripe）または銀行振込

## 現在の運用方針

- FarmProアカウントでログインして利用
- 農場アカウントごとにデータを分離
- Freeはデータを主に利用端末内へ保存
- Standard / Proはクラウド保存・自動バックアップ・複数端末同期に対応
- PWAとしてスマートフォンのホーム画面へ追加可能
- 手動バックアップJSONの保存・復元にも対応
- 本番サーバーは永続ディスクを使用

## 主な機能

- 繁殖牛台帳・個体カルテ
- 繁殖記録
- 人工授精・受精卵移植（ET）
- 妊娠鑑定・分娩予定
- 分娩記録・子牛管理
- 治療・投薬・ワクチン・BLV管理
- 予定・カレンダー
- 飼養管理
- 出荷販売・経費・月別収支
- マスター登録
- バックアップ・復元
- 牛情報取り込み（画像・PDF・CSV・Excel）
- A4横の牛成績表・通信簿系帳票のAI読み取り
- 印刷・レポート
- 運営者向け利用者管理
- Stripe決済・銀行振込申込管理

## 牛情報取り込み

現在対象としているA4横の牛成績表・通信簿系帳票について、次の処理に対応しています。

- 写真撮影と画像・PDF選択を分離
- 写真撮影時は背面カメラを優先
- 手ブレ・ぼやけ判定
- 帳票部分の自動トリミング
- 元写真とAI読み取り画像を確認可能
- 全体画像・強調画像・重なり付き分割画像を利用したAI解析
- 読み取り候補を利用者が確認してから正式登録
- 母牛本体の性別は登録前に利用者が選択

## 販売・運用

- Stripe本番価格・Webhook設定済み
- Standard / Proのサンドボックス決済からFarmProの自動プラン切替まで確認済み
- 銀行振込申込、通知メール、7日間の支払期限、期限切れ自動取消、入金確認後の有効化に対応
- 運営者管理画面から利用停止・利用再開が可能
- 利用規約、プライバシーポリシー、特定商取引法に基づく表記を公開
- ヘルプ・お問い合わせフォームを用意

## PCでの確認方法

```powershell

npm install
npm test
npm run build
```

サーバー：

```powershell
cd server
npm install
npm run build
```

ローカル開発時は、必要な環境変数を設定したうえで各サービスを起動します。本番環境の秘密情報や銀行口座情報はGitHubへ直接記載せず、環境変数で管理します。

## データ保存に関する注意

- IndexedDBの既存データを開発作業で安易に削除しない
- Free利用者は機種変更・修理・ブラウザデータ削除に備えて手動バックアップを保存する
- Standard / Proでも重要データは必要に応じて手動バックアップを保管する
- 本番サーバーのデータ保存先には永続ディスクを使用する
